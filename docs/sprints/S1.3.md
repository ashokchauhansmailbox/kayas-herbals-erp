# Sprint 1.3 — Authentication + RBAC + Audit + Seeds + Route Foundations ✅

**Parent sprint**: [Sprint 1 — Identity Core](./S1.md) &nbsp;·&nbsp; **Status**: Ready for review (2026-02-06)

## Objective
Turn the schema shipped in 1.1 + 1.2 into a **usable API**: real Supabase-JWT authentication, capability-based RBAC, immutable audit + activity logging, idempotent seeds, Pydantic schemas, and enough HTTP surface for administrators to manage users, roles, invitations, sessions, permissions, and audit logs.

## Roadmap
Sprint 1.3 was originally planned as "Purchase + Distributor + Customer" but was **swapped forward** with Auth/RBAC (see `docs/DECISIONS.md`) so subsequent sprints have real identity from day one. Purchase/Distributor/Customer moved to Sprint 1.4.

## Scope delivered

### Security core
1. **`app/core/security.py`** — HS256 JWT verification against `SUPABASE_JWT_SECRET`. Validates signature, `aud`, `exp`, `sub` (UUID). Also exports `mint_token()` for pytest.
2. **`app/deps.py`** — dependencies for `get_db`, `get_token_claims`, `get_current_user`, `require("perm.code")`, `request_id`.
3. **Session tracking** — every incoming JWT's `jti` is recorded in `sessions`. Revoked sessions return `auth.session_revoked` (401).

### Services
4. **`app/services/auth_service.py`** — resolves the local user, auto-provisions on first login, loads effective roles + permissions, honours suspension / deletion.
5. **`app/services/audit_service.py`** — `AuditContext(before/after → deepdiff)` writes to `audit_logs` **in the same transaction as the mutation**. `log_activity()` writes to `activity_logs`.

### Seed data (idempotent)
6. **`app/seeds/permissions.py`** — 89-entry permission catalogue.
7. **`app/seeds/roles.py`** — 9 system roles (super_admin, catalog_manager, inventory_manager, sales_manager, finance_manager, support_exec, marketing_manager, distributor, customer) with full role→permission mapping.
8. **`app/seeds/master_data.py`** — 8 units, 5 GST rates (0/5/12/18/28), 12 HSN codes (herbal/ayurvedic/cosmetics), 6 categories, 1 brand (Kaya's Herbals), 1 warehouse (KH-BLR-MAIN), 5 payment terms, 4 tax rules, 5 courier partners.
9. **`app/seeds/run.py`** — orchestrator. Idempotent on re-run; system roles' permission mapping is fully re-synced each time so adding a new permission code takes effect without manual DB work.

### Schemas
10. **`app/schemas/common.py`** — `ORMModel`, `Page[T]`, `Pagination`, `ErrorEnvelope`, `IdOut`.
11. **`app/schemas/auth.py`** — `MeOut`, `SessionOut`, `RevokeSessionIn`.
12. **`app/schemas/admin.py`** — `UserOut`, `UserUpdateIn`, `UserRoleAssignIn`, `RoleOut`, `RoleCreateIn`, `RoleUpdateIn`, `PermissionOut`, `InvitationCreateIn`, `InvitationOut`, `AuditLogOut`, `ActivityLogOut`.

### Routes (18 endpoints, all v1)
13. **`/auth/me`, `/auth/sessions`, `/auth/logout`**
14. **`/users`** (list + get + patch + assign role + revoke role)
15. **`/roles`** (list + get + create custom + update custom + delete custom — system roles protected)
16. **`/permissions`** (list, filter by module)
17. **`/invitations`** (list + create single-use token + revoke)
18. **`/audit/logs`, `/audit/activity`** (paginated read)

### API contracts
19. **OpenAPI baseline** (`docs/api/openapi.{json,yaml}`) regenerated; 18 routes.
20. **Postman collection baseline** (`docs/api/postman_collection.json`) — 23 requests across 7 folders. Generated deterministically from OpenAPI so CI drift-check enforces lock-step.
21. **`scripts/generate_postman.py`** + updated **`scripts/check_openapi_drift.py`** covering all three artifacts.

### Tests — 109 total (was 79 in Sprint 1.2)
- **`tests/test_auth.py`** — 11 cases: bearer missing/malformed, expired token, wrong audience, tampered signature, wrong secret, `alg=none` rejection, invalid subject, suspended user, sessions list, logout revocation.
- **`tests/test_rbac.py`** — 9 cases: every seeded permission installed, every seeded role has expected permission set, role isolation (customer vs. audit / users), system-role protection, custom role CRUD, permission catalogue readable.
- **`tests/test_audit_security.py`** — 10 cases: role update writes audit + diff, /me writes activity, audit pagination, OWASP scenarios (SQLi input safety, IDOR, missing bearer, missing permission, no leak of internals, `alg=none`), seed idempotency.
- **`tests/test_models_schema.py`**, **`tests/test_catalog_inventory.py`**, **`tests/test_migrations_cycle.py`** — 79 pre-existing cases unchanged.

## How to run locally
```bash
cp backend/.env.example backend/.env
docker compose up -d postgres redis
cd backend && alembic upgrade head && python -m app.seeds.run
cd backend && pytest -v                  # 109 tests
python scripts/generate_openapi.py       # regenerate on route change
python scripts/generate_postman.py       # keep in lock-step
```
