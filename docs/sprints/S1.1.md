# Sprint 1.1 — Database Foundation ✅

**Parent sprint**: [Sprint 1 — Identity Core](./S1.md) &nbsp;·&nbsp; **Status**: Complete (2026-02-06)

## Objective
Deliver the SQLAlchemy + Alembic substrate on top of which every Sprint 1.x sub-sprint (auth middleware, RBAC, seeds, routes) will build. **Zero business logic** in this slice — only schema.

## Scope (in)
- `app/db/` — `base.py`, `session.py`, `mixins.py`, `types.py`
- `app/models/identity.py` — 9 tables (users, roles, permissions, role_permissions, user_roles, sessions, user_invitations, audit_logs, activity_logs)
- `app/models/master_data.py` — 10 tables (units, gst_rates, hsn_codes, categories, brands, warehouses, payment_terms, tax_rules, transporters, courier_partners)
- `alembic.ini` + `migrations/env.py` + `migrations/script.py.mako`
- Migrations `001` extensions + enums, `002` identity core, `003` master data
- Per-migration docs under `/docs/database/`
- `tests/test_models_schema.py` — 32 model-contract cases (no DB required)
- `tests/test_migrations_cycle.py` — 5 end-to-end cases (`upgrade head → downgrade base → upgrade head`, enum + extension presence, autogenerate drift = 0)
- `app/api/v1/routes/health.py` — `/live`, `/ready`, `/db` endpoints
- Broken router import in `app/api/v1/__init__.py` fixed

## How to run locally
```bash
# One-time
cp backend/.env.example backend/.env   # ensure DATABASE_URL_SYNC is set
docker compose up -d postgres          # or use a native cluster on :5432

# Migrate
cd backend && alembic upgrade head

# Tests
cd backend && pytest -v
```
