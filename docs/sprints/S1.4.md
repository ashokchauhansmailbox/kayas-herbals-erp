# Sprint 1.4 — Purchase + Distributor + Customer

_Kick-off: 2026-02-06 · Owner: Kaya BOS engineering agent · Depends on: `sprint-1.3-stable`_

## 1. Goal

Extend the domain model with three new bounded contexts:

1. **Purchase** — vendors, purchase orders, GRNs, vendor invoices.
2. **Distributor** — distributor accounts, tiers, price lists, KYC.
3. **Customer** — extended customer profiles, addresses, wallets, referrals.

Deliver the schema (two reversible migrations), the SQLAlchemy 2 async models,
Pydantic v2 schemas, RBAC-guarded CRUD routes for the master resources, and a
comprehensive pytest suite. Transactional workflows (PO approval / GRN posting /
vendor-invoice reconciliation / wallet debits / referral payouts) are scoped to
Sprint 1.5 (Orders + Billing + Payments) where they naturally compose with the
downstream sale side.

### 2.4 Routes (`app/api/v1/routes/`)

Master-resource CRUD only in Sprint 1.4. Every mutating route:
- wears `Depends(require("<perm>"))`,
- wraps the mutation in `AuditContext(...)`,
- returns the unified error envelope.
