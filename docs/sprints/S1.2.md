# Sprint 1.2 — Catalog + Inventory ✅

**Parent sprint**: [Sprint 1 — Identity Core](./S1.md) &nbsp;·&nbsp; **Status**: Ready for review (2026-02-06)

## Objective
Ship the SQLAlchemy models, Alembic migrations, documentation, and tests for the **product catalog** and **inventory** layers. This is still database-only — no HTTP routes ship in 1.2 (auth + routes land in 1.6).

## Scope delivered (approved 14 items)

### Catalog (migration 004)
1. **Product catalog** — `products` with FSSAI/AYUSH/manufacturer/shelf-life/storage metadata.
2. **Product variants** — `product_variants` (shipped SKUs with MRP + base_price + barcode).
3. **Certifications** — `certifications` (AYUSH, FSSAI, organic, lab) with `valid_until`.
4. **Product images** — `product_images` (variant-scoped, sortable, primary flag).
5. **Product documents** — `product_documents` (spec sheets, brochures, MSDS, lab reports).
6. **Pricing history** — `product_price_history` (selling-price append-only journal).
7. **Purchase price history** — `purchase_price_history` (buy-price append-only; vendor/po FKs deferred to Sprint 1.3).

### Inventory (migration 005)
8. **Batch management** — `batches` with mfg/expiry dates + cost-per-unit + supplier ref.
9. **Inventory ledger** — `stock_ledger` (append-only, state-machine-friendly, indexed on `variant_id + warehouse_id + at`).
10. **Inventory snapshots** — `stock_snapshots` (materialised balance, natural-key functional unique index).
11. **Stock transfers** — `stock_transfers` header + `stock_transfer_items` lines (with `from ≠ to` CHECK and positive-qty CHECK).
12. **Stock adjustments** — `stock_adjustments` with mandatory `reason_code`.
13. **Stock alerts** — `stock_alerts` (low_stock / near_expiry / expired lifecycle).
14. **Stock valuation view** — `v_stock_valuation` (qty × cost_per_unit + days_to_expiry).

Plus: migrations 004 & 005; per-migration docs; unit + integration + smoke tests.
